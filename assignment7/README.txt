ASSIGNMENT 7 - HTML, CSS and JavaScript

This folder contains 9 mini-projects. Each question has its own folder with:
- index.html
- style.css
- script.js

How to run:
1. Open the assignment7 folder in VS Code.
2. Open the question folder you want to test.
3. Open index.html in a browser (or use the Live Server extension).
4. The HTML file loads its matching CSS and JavaScript files.

Questions:
1. Dynamic Product List Manager
2. Live Character Counter
3. Multi-Step Form
4. Theme Switcher
5. Image Gallery Modal
6. Real-Time Table Filter
7. Mouse Coordinates Logger
8. Custom Dropdown
9. Form Submit Blocker

Q5 uses Picsum image URLs, so an internet connection is needed to load the gallery images.
