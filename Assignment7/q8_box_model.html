1. Anatomy of the CSS Box Model

Margin (24px) Border (8px) Padding (24px) Content Area
MARGIN (Outer spacing separating elements)
BORDER (Visible perimeter framing padding)
PADDING (Internal breathing room around content)
CONTENT

Text, images, or child elements live inside this innermost rectangle.

2. box-sizing: content-box vs. border-box

Both boxes below are explicitly declared with width: 300px, padding: 25px, and border: 10px solid.

Default: content-box

Declared Width: 300px

Actual Rendered Width: 300 + 50 + 20 = 370px

Padding and border are added outside the 300px content width.

Modern: border-box

Declared Width: 300px

Actual Rendered Width: 300px exact

Padding and border are absorbed inside the 300px total width.
