1. Frontend, Backend and Full-Stack Development

Frontend development is the part of a website that users see and interact with. It includes the layout, buttons, forms, images and navigation. Common technologies are HTML, CSS and JavaScript. Example: the product page, search bar and shopping cart interface on an online shopping website.

Backend development handles the server-side work. It receives requests, applies business rules, manages authentication and communicates with databases. Common technologies include Java, Python, PHP, Node.js and SQL. Example: checking a customer's login details and calculating an order total.

Full-stack development combines frontend and backend development. A full-stack developer can work on the user interface as well as the server and database connection. Example: building an online shopping application, including its product pages, order processing and data storage.

3. How a Browser Requests and Displays a Web Page

  1. The user enters a website address (URL) or clicks a link.
  2. The browser finds the server's IP address using DNS.
  3. The browser establishes a connection to the server. HTTPS also establishes an encrypted TLS connection.
  4. The browser sends an HTTP request for the page.
  5. The web server processes the request and returns a response, such as HTML, CSS, JavaScript and images.
  6. The browser parses the HTML to build the DOM and the CSS to build the CSSOM.
  7. The browser combines the required information, calculates layout, paints the page and displays it.
  8. JavaScript may run and request additional data or update parts of the page.

5. What is a Web Server?

A web server is software (and the computer running it) that receives HTTP/HTTPS requests from clients and returns web content or responses. It can serve static files and can pass dynamic requests to application code.

Common examples are Apache HTTP Server, Nginx, Microsoft IIS, Caddy and LiteSpeed Web Server.

6. Roles in a Web Development Project

  • Frontend Developer: creates the user interface, makes pages responsive and accessible, and connects the interface to backend APIs.
  • Backend Developer: builds server-side logic, authentication, APIs and application rules; also works with data storage.
  • Database Administrator (DBA): installs, configures, secures, backs up and monitors databases, and helps maintain performance and data availability.

8. Static and Dynamic Websites

A static website displays pages whose content is generally fixed and delivered as stored files. The same page is normally sent to every visitor unless the files are changed by the developer. Example: a simple portfolio or informational website made only with HTML and CSS.

A dynamic website can generate or update content based on user input, stored data, login status or other conditions. It commonly uses backend code and databases. Example: an online banking dashboard showing the signed-in customer's account information.

9. Five Web Browsers and Their Rendering Engines

BrowserRendering engineExplanation

Microsoft EdgeBlinkModern Edge is based on Chromium and uses Blink for rendering.
Mozilla FirefoxGeckoMozilla's rendering engine, developed independently from Blink and WebKit.
Apple SafariWebKitApple's browser engine, used by Safari on Apple platforms.
OperaBlinkModern Opera is Chromium-based and uses Blink.

Rendering engines differ in their internal implementation, standards support, performance choices, layout and painting behavior, and timing of support for newer web features. As a result, developers should test websites in more than one browser. Note that a browser's JavaScript engine is separate from its rendering engine (for example, Chrome uses V8).

10. Basic Web Architecture Flow: Client, Server, Database and APIs

The client communicates with the server through HTTP requests. The server may call APIs or application services and read or update information in a database before returning a response.

WEB SERVER
Receives the request
↓ Routes request
APPLICATION / API
Business logic and data processing
↕ Database query / result
DATABASE
Stores users, products and records
↑ HTTP response (JSON / HTML)
CLIENT DISPLAYS RESULT

API (Application Programming Interface): a defined way for software components to communicate. For example, a frontend may call /api/products and receive product information in JSON format.

Conclusion

Web development combines frontend interfaces, backend processing, servers, APIs and databases. Understanding how these parts communicate helps developers build websites that are useful, reliable and maintainable.
