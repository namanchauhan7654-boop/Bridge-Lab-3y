# Assignment 3 — HTML Only

This folder contains 15 separate HTML files, one for each assignment question.

- Each page has `<!DOCTYPE html>` and a meaningful `<title>`.
- The solutions use HTML only: no CSS and no JavaScript.
- HTML comments are included where they help explain structure.
- Replace placeholder email addresses and phone numbers with your own details before submitting.
- Product and travel images use placeholder image URLs and require an internet connection.

## Open in VS Code
1. Extract `Assignment3.zip`.
2. Open VS Code.
3. Select File → Open Folder → Assignment3.
4. Open any numbered HTML file in a browser to view it.
