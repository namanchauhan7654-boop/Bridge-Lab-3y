ASSIGNMENT 10 — BOOTSTRAP 5

Each question has its own folder containing:
- index.html
- style.css

How to run:
1. Extract the ZIP file.
2. Open the required question folder.
3. Open index.html in a browser (or use VS Code Live Server).
4. An internet connection is required for Bootstrap CDN, Google Fonts, and remote images.

Notes:
- Bootstrap 5.3.3 is loaded from the official jsDelivr CDN.
- The responsive navbar, dismissible alert, and carousel use Bootstrap's bundle where needed.
- The remaining layouts use Bootstrap CSS classes and custom CSS only.
