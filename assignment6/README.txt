ASSIGNMENT 6 - JavaScript Asynchronous Programming

This folder contains 10 separate JavaScript files (Q1-Q10).

Run a question:
    node Q1_async_coffee_maker.js

Requirements:
- Node.js (recent version recommended; Q6 uses built-in fetch).
- Internet connection for Q6 (Fake Store API).
- Some questions intentionally use random failures. Run them again to see different outcomes.

Note for Q5:
- The file runs the nested-callback version by default.
- To run the async/await version, comment out runWithCallbacks() and uncomment runWithAsyncAwait().
