# Assignment 2 — HTML Only

This folder contains one separate HTML file for each of the 20 tasks.

## Files
- `01-my-first-web-page.html` through `20-complete-semantic-webpage.html`
- Each file includes `<!DOCTYPE html>`, a meaningful `<title>`, and HTML comments where helpful.
- Only HTML is used; there are no CSS or JavaScript files.

## How to view
Open any `.html` file in a web browser, or open the `Assignment2` folder in VS Code and use the browser to preview each file.

## Note about Task 3
The Doraemon image uses an external Wikimedia Commons file URL. An internet connection is needed to load it. You can replace the `src` value with another image URL if desired.
