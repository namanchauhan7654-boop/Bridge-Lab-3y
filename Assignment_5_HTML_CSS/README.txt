ASSIGNMENT 5 - HTML AND CSS

Folder name: Assignment_5_HTML_CSS

This folder contains 10 separate HTML files and 10 matching CSS files.
Each HTML file links to its matching CSS file using a relative stylesheet link.

How to open:
1. Extract Assignment_5_HTML_CSS.zip.
2. Open the extracted folder in VS Code.
3. Open any numbered HTML file in a browser (or use Live Server).
4. Keep each HTML and CSS pair in the same folder.

No JavaScript or external framework is used. Some pages use externally hosted Unsplash images as visual content.
