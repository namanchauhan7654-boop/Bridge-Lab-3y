ASSIGNMENT 6 - HTML AND CSS

Folder name: Assignment6

This folder contains 10 separate HTML files and 10 matching CSS files.
Each HTML file links to its matching CSS file. Keep each pair in the same folder.

How to use:
1. Extract Assignment6.zip.
2. Open the Assignment6 folder in VS Code.
3. Open any numbered HTML file in a browser or with Live Server.
4. Keep all HTML and CSS files together.

The assignments use HTML and CSS only, with Flexbox and/or Grid for layout.
No JavaScript or external CSS framework is included.
