CSS box-sizing Comparison

Both boxes below have identical CSS declarations: width: 320px;, padding: 30px;, and border: 8px solid;.

1. Default (content-box)

Declared Width: 320px

Total Rendered Width: 396px

Under the browser default content-box, padding (30px × 2) and borders (8px × 2) are added on top of the 320px width, making the box 76px wider than declared.

2. box-sizing: border-box;

Declared Width: 320px

Total Rendered Width: 320px

With border-box, padding and borders are included inside the declared 320px width, keeping layout dimensions predictable and aligned.
