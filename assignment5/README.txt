ASSIGNMENT 5 - JavaScript

This folder contains one separate JavaScript file for each question (Q1-Q9).

How to run:
1. Install Node.js.
2. Open a terminal in this folder.
3. Run a file using: node Q1_greet_callback.js
4. Replace the filename with the question you want to test.

- Q2_apply_operation.js
