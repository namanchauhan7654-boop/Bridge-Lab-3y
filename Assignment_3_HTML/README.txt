ASSIGNMENT 3 - HTML ONLY

Folder: Assignment_3_HTML

This folder contains the separate HTML files for all 20 assignment questions.
Question 3 also uses introduction.html and hobby.html.
Question 4 also uses navigation.html and welcome.html.
Question 17 is split into 17a_form.html and 17b_result.html.

How to use:
1. Extract this folder.
2. Keep all files together in the same folder.
3. Open the required .html file in a web browser.
4. For iframe examples that load local pages, keep the related files in this folder.

Notes:
- Question 4 uses frameset/frame, which are obsolete in HTML5 but included because the assignment specifically requests them.
- The payment form is for HTML demonstration only. Do not enter real card details.
- Forms using action="#" are front-end examples and do not process or store submissions.
